# タジルゲートにおいてさようなら

深層ナムル教の聖堂を舞台にした、一人称の3Dホラーゲームです。ブラウザだけで遊べます。

- `index.html` … パソコン版
- `mobile.html` … スマホ版（横画面）

インターネットに接続した状態で、ブラウザで開いてください。

## クレジット
- 壁・床・柱・長椅子のテクスチャ：ambientCG（CC0）https://ambientcg.com
- 足音・ドア・うなり声・環境音・心臓の音：OpenGameArt（CC0）Fantozzi, ambient-horror, stone-door, monster-snarls ほか
- 木・濡れた床・石の足音：OpenGameArt（CC0）[kdd] Different Steps ほか
